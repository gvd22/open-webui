## 2. Integration Corrections

The merge retained upstream v0.11.3 behavior while preserving the existing
workspace contracts:

- Native terminal output display and workspace object opening coexist in Chat.
- HTML serve URLs, DOCX/PPTX output handling, and Canvas/Web Preview structured
  output are integrated instead of choosing one branch wholesale.
- PDF all-page/single-page navigation keeps the shared 10-percent zoom, pan,
  cancellation, and accessibility behavior.
- Collaborative Notes disable Tiptap's local UndoRedo extension while the
  y-prosemirror undo plugin is active. This removes duplicate keyed plugins.
- The first real Canvas edit is no longer discarded as a presumed editor-mount
  event; programmatic changes remain guarded by content comparison.
- Full-app tests dismiss the native release-notes dialog deterministically and
  wait for the application after reloads.
- Runtime Browser diagnostics start their own local HTTP server when necessary,
  so test order no longer determines the result.

## 4. Remaining Gaps

1. **Protected multi-file Browser apps:** initial HTML loads, but a sandboxed
   local app cannot authenticate a separate `app.js` request through the
   protected proxy. The expected-failure regression remains intentional. Do not
   weaken iframe same-origin isolation or make the proxy public as a shortcut.
2. **Pyodide-only live journey:** the CSV upload journey is skipped in this
   Terminal-enabled instance by design. Pyodide source and unit regressions pass,
   but this report does not claim a fresh Pyodide-only browser run.
3. **Real-model evidence:** no new model-directed Canvas/Web Preview journey was
   run specifically for the v0.11.3 merge. The prior v0.11.1 evidence remains
   useful but is not substituted for current-version proof.
4. **Inherited warnings:** the production build reports existing Svelte
   accessibility and self-closing-element warnings. They do not fail the build,
   but this acceptance does not classify the inherited warning backlog as clean.

The upgrade is suitable for continued isolated development and review. The
remaining gaps must stay explicit in any production-readiness decision.
